介绍

SnowLuma 是什么、能做什么，以及它的三种使用形态与发行结构

SnowLuma 是一个面向 NTQQ（QQ 桌面客户端）的远程协议框架。它把 QQ 桥接到 OneBot v11 生态：一个 native addon 通过 ptrace 级注入把 hook 打进正在运行的 QQ 进程（Linux 进程名 qq，Windows QQ.exe），解析它的内部数据包，再以 OneBot v11 的形式通过 HTTP / WebSocket / 反向 WS / HTTP 上报暴露出来。

围绕这个内核，SnowLuma 还提供：

  • OneBot v11 适配器 —— HTTP API 服务、WebSocket 服务、反向 WebSocket、HTTP 事件上报，任意组合。
  • NTQQ 桥接 —— 直接对接真实 QQ 客户端，无需协议号、无需独立登录。
  • 多账号 —— 一个 UIN 一个 OneBot 实例，自动检测、自动接入，无需手动配置。
  • 内置 WebUI —— 浏览器里管理账号、配置、查看状态。
  • TypeScript SDK —— @snowluma/sdk，写类型完备的 OneBot 客户端。
  • MCP 服务 —— @snowluma/mcp，让支持 MCP 的 AI 客户端查询并调用 OneBot action。

发行结构

每个平台在 GitHub Releases 提供两种 tarball：

包名是否含 Node.js适用
SnowLuma-<TAG>-<platform>-<arch>.tar.gz（full）内置 Node.js 运行时机器上没有 Node，开箱即用
SnowLuma-<TAG>-<platform>-<arch>-lite.tar.gz（lite）不含 Node.js（包小很多）机器已装 Node.js ≥ 22（推荐 Node 24 LTS）

已发布的平台 / 架构：linux-x64、linux-arm64、win-x64。

Info

SnowLuma 需要 Node.js ≥ 22。2026 年 Node 24（"Krypton"）是 Active LTS，22（"Jod"）已进入 Maintenance LTS，因此 lite 包推荐安装 Node 24 LTS（22 仍可用）。full 包自带运行时，无需安装。来源：nodejs.org。

VNC5900仅 Docker 内部：原生远程桌面。官方模板不对外映射
noVNC6081仅 Docker：浏览器远程桌面，扫码登录

端口、监听地址等可在配置里改，详见配置参考。

Warning

不要把 noVNC / WebUI / OneBot 端口裸暴露在公网。Docker 的远程桌面没有固定默认密码，第一次启动会随机生成，只在容器日志里打印一次。
